# KI BLOX

Voxel-Welt zum Bauen, Fliegen und Kämpfen — inspiriert von Blockwelten und Ki-Duellen.

Sammle sieben Drachenkugeln, rufe den Drachen, wähle einen Wunsch. Super Saiyan ab 4500 Ki.

## Spielen

- **WASD** bewegen, **Maus** umsehen (Klick sperrt den Pointer)
- **Leertaste** springen, nochmal in der Luft: Flugmodus
- **Halten** (Linksklick) abbauen, **Rechtsklick** setzen
- **Q halten und loslassen**: geladener Ki-Stoß
- **R** Dash (kostet Energie)
- **F** Super Saiyan (Aura zehrt Energie)
- **ESC** Pause

Auf dem Handy: Stick links, Blick rechts, Aktionsknöpfe unten.

Der Fortschritt liegt lokal im Browser.

## Technik

React 19, TanStack Start, Three.js (Chunks, Ambient Occlusion, Bloom), Zustand, localStorage.

## Entwickeln

```bash
npm install
npm run dev
```
